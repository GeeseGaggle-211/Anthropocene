# Cartographic map assets

The 29 RGBA PNGs in `Assets/_Anthropocene/Resources/MapArt` are original project drawings, authored as SVG recipes in `Tools/Art/Build-SymbolicAssets.cjs` and rasterized at 256 × 256. Reusable SVG exports are kept in `Tools/Art/Sources`. Edit the recipes when changing the set, then regenerate both formats. No third-party artwork or fonts are shipped with these assets. The exporter uses Sharp (Apache-2.0) from the workstation's bundled Node dependencies; the game does not depend on Node or Sharp. No additional Unity package is required to display the PNGs.

The visual target is the user's **Option C — Minimalist & Iconic (with Elevation)** image embedded in the reconciled [Drive proposal](https://docs.google.com/document/d/1bghyyEUw55bhM0NQRyzHP6RlfU5JM6LV/edit). It was successfully recovered from the DOCX media on September 13 and is preserved as [OptionC-reference.png](Art/OptionC-reference.png) for follow-on art work. That supplied reference is documentation, not a shipped game asset. The earlier implementation used the written description without seeing that image, producing dark flat terrain and monochrome symbols. Its renderer also filled occupant slots with opaque panels. Passing import and slot-size checks did not establish visual fidelity; the user correctly rejected that result.

The replacement uses warm earth/blue water colours, outlined and shaded illustrations, genuine alpha, and independent semantic layers. The set contains nine ground families, five vegetation motifs, three land-use overlays, two settlement hooks, camp/hunter icons, five distinct wild-species silhouettes, one marked livestock icon and two freshwater/oasis icons. The antelope uses `unit_herd_wild` for filename compatibility. These are original interpretations of the supplied reference, not extracted pieces of its illustrated sheet. They keep gameplay geography authoritative: no baked forests, guessed shorelines, artificial rivers or copied elevation from the concept.

Density comes from deterministic motif placement. At normal zoom low/medium/high cover uses three/four/seven motifs; occupied tiles use smaller motifs and distant zoom drops them before actor/contour identity. Rivers and exact elevation boundaries remain procedural. Shore edges are drawn only against observed land neighbours. High cultivation and village assets remain extension hooks. A mobile camp is drawn once, in its selectable occupant slot.

Both semantic tilesets use the same illustrations and retain glyph fallbacks. `SpriteTint` is independent of glyph `Tint`, preserving the artwork's palette; foreign camps/hunters also have a warm tint and diamond marker. High contrast uses darker ground, stronger contour lines and white selection corners. Selections use open corner marks, never filled slot rectangles. Count labels have a narrow text outline; food and freshwater badges occupy separate areas. The importer uses single sprites, alpha, trilinear filtering with mipmaps for zoom reduction, clamp wrapping and no compression. Contour/selection strokes have feathered edges. Preserve existing GUIDs when replacing art.

To regenerate, run the exporter with Node, passing the local Sharp package directory as its first argument. It checks all 20 overlays for RGBA and substantial transparent negative space and writes a contact sheet from the exported PNGs to ignored `TestResults/CartographicAssets.png`.

The development-player smoke route also captures illustrative fixtures through the production Unity renderer in both contrast sets, at actual tile size, including every species, vegetation tiers, six occupants and distant zoom. Actor illustrations narrower than 13 screen pixels simplify to their outlined semantic glyphs. `Tools/Art/Check-PlayerArt.cjs <sharp-directory> <smoke-output-directory>` checks six pixels of map negative space against the same tile with a selected camp, verifies that the camp actually rendered, and requires the complete capture set and gameplay/save result. Those fixtures never enter authoritative world state. Inspect the playable screenshots as well as the asset sheet; a good source illustration alone is not acceptance evidence.
